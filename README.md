# rsm_utils

Tools for creating 3D Reciprocal Space Mapping from scan images.

## Setup

**1. Create and activate a virtual environment**

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
```

**2. Install the package**

```bash
pip install -e .
```

This installs `rsm_utils` in editable mode along with all dependencies.
